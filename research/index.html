Research

Research areas and impact in online ML, drift detection, deep learning, and IoT security.

Primary Research Areas

Broad themes distilled from my publication portfolio — spanning IoT security, adaptive and online machine learning, streaming analytics, edge AI, and related application domains.

IoT Intrusion Detection & Network Security

Designing machine-learning defences for IoT and edge networks — from lightweight tree-based classifiers and ensemble stacking to real-time analytics pipelines, botnet detection, and privacy-aware attack classification on evolving traffic.

Keywords: Intrusion Detection · Network Security · Botnet Detection · Privacy-Preserving ML

Representative publications: LIRAD: Lightweight tree-based approaches on resource constrained IoT devices; Tachyon: Enhancing stacked models using Bayesian optimization for intrusion detection; AURA: Adaptive unified real-time analytics for IoT intrusion detection; CITADLE: Cyber intrusion tracking and defense layered environment

Online Machine Learning & Concept Drift

Building adaptive models that learn from streaming data and respond when attack patterns or sensor behaviour shift over time — including online ensembles, drift-aware updating, and sequential anomaly detection with feedback.

Keywords: Concept Drift · Online Ensembles · Streaming ML · Adaptive Learning

Representative publications: OASIS: Online adaptive ensembles for drift adaptation on evolving IoT data streams; Sequential anomaly detection using feedback and prioritized experience replay; Knox: Lightweight machine learning approaches for automated detection of botnet attacks

Streaming Analytics & Complex Event Processing

Architectures for ingesting, processing, and reasoning over high-velocity IoT data streams using complex event processing engines, Kafka/Flink pipelines, and lightweight ML at the edge for timely threat and event detection.

Keywords: Complex Event Processing · Stream Processing · Real-Time Analytics · Apache Kafka / Flink

Representative publications: An ingestion based analytics framework for complex event processing engine in IoT; HeuristiX: Adaptive event processing using lightweight ML on edge devices; Streamlined data pipeline for real-time threat detection and model inference; Analyzing events using IoT data streams in a smart city scenario

Smart Cities & Intelligent Transportation

Predictive analytics on urban IoT data streams for traffic forecasting, congestion modelling, and intelligent transportation — combining probabilistic models, evolutionary learning, and large-scale REST/streaming frameworks.

Keywords: Smart Cities · Traffic Prediction · VANETs · Urban IoT

Representative publications: Real-time probabilistic approach for traffic prediction on IoT data streams; An evolutionary approach for congestion prediction on IoT data streams in smart city environment; A REST framework on IoT streams using Apache Spark for smart cities; A systematic review of VANET routing protocols for intelligent transport systems

Lightweight & Edge Machine Learning

Deploying accurate yet resource-efficient models on constrained devices — pruned tree ensembles, compact CNNs, Raspberry Pi clusters, and embedded hardware such as Jetson Nano for real-time inference at the edge.

Keywords: Edge Computing · Lightweight ML · Embedded AI · Resource-Constrained Devices

Representative publications: LIRAD: Lightweight tree-based approaches on resource constrained IoT devices; Optimized tree-based ensembles for intrusion detection in internet of things; SpectralRepNet: Real-time image dehazing for edge surveillance; CITADLE: Cyber intrusion tracking and defense layered environment

Deep Learning & Computer Vision

Neural architectures for time-series anomaly detection, network intrusion classification, agricultural disease recognition, and surveillance under adverse conditions — spanning Bi-LSTMs, tree-based CNNs, and spectral reparameterization networks.

Keywords: Deep Learning · Computer Vision · Bi-LSTM · Image Dehazing

Representative publications: Attention-based bi-LSTM for anomaly detection on time-series data; Robust detection of network intrusion using tree-based convolutional neural networks; Demeter: Enhancing paddy disease detection using deep ensembles and few-shot learning; SpectralRepNet: Real-time image dehazing for edge surveillance

Mobile Crowdsensing & Mechanism Design

Incentive-compatible auctions and truthful mechanisms for IoT-based mobile crowdsensing — balancing data quality, budget constraints, and strategic behaviour among participants in participatory sensing platforms.

Keywords: Crowdsensing · Auction Theory · Mechanism Design · Quality-Aware Sensing

Representative publications: A truthful mechanism for time-bound tasks in IoT-based crowdsourcing with zero budget; A quality aware multi-unit double auction framework for IoT-based mobile crowdsensing

Healthcare & Environmental IoT

AI-enabled monitoring for health and environmental sensing — including fall detection for dementia care, diabetes screening from wearable data, and automated water-quality assessment in smart-city and agricultural settings.

Keywords: Healthcare IoT · Fall Detection · Water Quality · Precision Agriculture

Representative publications: CURA: Real time AI and IoT based fall detection systems for dementia patients; IoT-enabled early detection of diabetes diseases using deep learning; Automated detection of water quality in smart cities using various sampling techniques; Demeter: Enhancing paddy disease detection using deep ensembles and few-shot learning
